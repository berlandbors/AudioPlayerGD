# AudioPlayerGD

Минималистичный аудиоплеер для Google Drive.

Формат плейлиста:

[
  {
    "id": "1tR9ivOcaNZQlosacXaUK4a88oYZMskPb",
    "title": "Летний дождь",
    "artist": "Неизвестный исполнитель"
  }
]

Что делает код автоматически:
- принимает только `id`, `title` и `artist`;
- сам преобразует `id` в прямую ссылку Google Drive;
- поддерживает и старый формат со ссылкой `url`, если нужно.

Как запустить:
1. Откройте папку проекта.
2. Запустите локальный сервер:
   `python -m http.server 8000`
3. Откройте в браузере:
   `http://localhost:8000/`

Важно:
- файл в Google Drive должен быть общим ("Anyone with the link").
- используйте аудиофайл в поддерживаемом формате (mp3, wav, m4a и т.п.).
