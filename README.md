# AudioPlayerGD

Приложение-плеер для аудиофайлов из Google Drive.

Важно:
- В файле `playlist.json` должны быть реальные ссылки на аудиофайлы.
- Для файлов Google Drive лучше использовать ссылки вида:
  `https://drive.google.com/file/d/ID/view?usp=sharing`
- Приложение автоматически преобразует их в прямую ссылку для скачивания.
- Для локального запуска откройте `index.html` в браузере.
